
# 度朔·服务端

度朔山、度灵欢，引入鬼门关。

> _上古之人，有神荼、鬱壘者，昆弟二人，性能執鬼，居東海度朔山上，立桃樹下，簡閱百鬼。_
> —— 汉·王充《論衡·亂龍》

**度朔**是一个用以通过监控数字活动来进行生死判断的一个系统。

> 若我在某一刻停止了一切数字生活，这样的情况达到一定的时间，则我便已死亡。若我死亡，我的亡语将被执行。

## 架构设计

**_本仓库内为度朔系统的服务端代码。_**

我们使用 Python 语言进行开发，并使用 FastAPI 框架运行 Web 服务、使用 SQLite 数据库进行数据存储。

服务端为纯后端服务，不提供任何前端页面。

## 功能特性

- 启动后开始死亡判定倒计时。
- 接收客户端数字活动并重置倒计时。
- 提供服务端状态查询。
- 支持修改除服务端口外的运行配置。
- 倒计时结束时执行配置的最终任务。
- 提供配对窗口、二维码和桌面端配置码。
- 支持客户端之间通过短报文缓存进行通信。

## 快速开始

```bash
pip install -e .
python src/main.py
```

默认监听 `0.0.0.0:8000`，数据库文件为 `dushuo.db`。
